# added by inserting directly into uplifting_vault_v2.db (scraped from abora-recordings.com's tracklist page), NOT into the
# spreadsheet. Running "python import_spreadsheet.py" wipes the DB and rebuilds it from the spreadsheet alone, which will
# DROP episodes 702-707 again until the spreadsheet itself is updated with them. If you run the Full Update above and the
# episode count drops back to 701, that's why — re-insert the missing episodes (or update the spreadsheet) afterward.
# DO NOT try to append new rows to this xlsx with openpyxl/pandas: many historical cells are Excel formulas with cached
# values, and any library that re-saves the file drops those caches, silently corrupting most of the historical tracklist
# data (confirmed: openpyxl re-save took the DB from 17,550 tracks down to 8,621). Only edit this file in real Excel/Sheets,
# or add new episodes directly to the SQLite DB as done here.
